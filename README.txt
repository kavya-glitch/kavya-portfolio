KAVYA PENTI PORTFOLIO

Files:
- index.html : page content
- style.css  : responsive styling
- script.js  : mobile navigation and current year
- assets/    : add your resume PDF here as Kavya_Penti_Resume.pdf

HOW TO PREVIEW
1. Extract the ZIP folder.
2. Open index.html in Chrome or Edge.

BEFORE PUBLISHING, UPDATE THESE PLACEHOLDERS IN index.html:
- YOUR_EMAIL@example.com and the visible email label
- LinkedIn profile URL
- GitHub profile URL
- Resume PDF: place your file at assets/Kavya_Penti_Resume.pdf
- Confirm project descriptions, technology lists and repository links

PUBLISH FREE WITH GITHUB PAGES
1. Create a GitHub repository named kavya-portfolio.
2. Upload index.html, style.css, script.js and the assets folder.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. GitHub will provide your public website URL after deployment.
